Prerequisites & reference
1. SSO setup — run once (re-run if auth file is older than 8 hours):
npx playwright test sso_setup.ts --project=setup --headed
2. View HTML report after a run:
npx playwright show-report
The launcher server must be running (started via start-launcher.bat) for the Run button to work. The server window can be minimised — just don't close it.
